# PDF 提取为可检索 txt

把用户自己的 PDF 做成便于阅读和查找的纯文本。先判断有没有文字层，再分路。文字层走第 1–7 节，扫描版走第 8 节。每条路上的数字阈值都来自跑通的那一本，换书要重新量。

两本样本都是《剑桥科学史》第七卷：

- 英文版有文字层。参考实现 `/tmp/extract_chs7_txt.py`。成品在桌面和 `~/KindleBackup/cambridge-history-7-en/`。
- 中文版是扫描件，722 页，文字层为空。参考实现 `/tmp/ocr-batch.swift` 和 `/tmp/chs7zh-build.py`。成品在桌面和 `~/KindleBackup/cambridge-history-7/剑桥科学史7.txt`。临时脚本重启后可能消失。

---

## 目标与边界

输入：用户自己的 PDF。第 0 节决定走文字层还是 OCR。

输出：一个 UTF-8 txt。

- 开头是目录，条目缩进对应大纲层级，页码用书上的印刷页码。
- 正文按印刷页码切开，标记写成 `[p. 14]`，和目录里的页码是同一套。
- 一段话连成一段。行末被拆开的单词接回去。真正的复合词连字符保留，例如 `nineteenth-century`。
- 索引按词条拆开，双栏先读左栏再读右栏。

不做的事：

- 扫描版不要走第 2–5 节。没有文字层就进第 8 节。
- 不要用词典把粘连的长串强行切开。见文末「做过、不要再做」。
- 不要把整本书贴进对话。文件写到磁盘，回复里只给路径、标记格式和抽查结果。

## 0. 先分型

抽 3 页看文字层：一页章节开头、一页章节中部、一页索引或目录。

| 现象 | 走哪条路 |
| --- | --- |
| `extract_text()` 能得到完整句子 | 本文这条路 |
| 几乎没有字符，或只有页眉 | 扫描版，改 OCR |
| 有字但词被切成 `T errell`、句号后没空格 | 换提取器，先别写清洗规则 |

这一本用 PyMuPDF（`fitz`）比 pypdf 干净：没有 `T errell` 这种词内空格，`1770. In 1795` 的空格还在，裁切标记也没进来。pypdf 仍可用，但要多修一轮。决定之前两套都抽同一页，保留更好的那套。

依赖：本机已有 PyMuPDF 1.26。词表用 `/usr/share/dict/words`。

## 1. 量印刷页码，不要写死偏移

目录里的「第 14 页」和 PDF 的第 14 页不是一回事。标记必须用书上印的页码，否则无法和目录、Kindle 对上。

做法：

1. 从目录取一个已知锚点。这一本是第 1 章印在第 1 页。
2. 在 PDF 里找到该标题所在的页。这一本是 0-based index 29。
3. 算出偏移：`印刷页 = pdf_index - 28`。只对阿拉伯数字正文成立。
4. 再核一个远处锚点。这一本索引印在第 735 页，对应 index 763。两个锚点都对上才采用。
5. 前辅文单独处理。这一本 index 7 的页脚是 vii，所以罗马数字页 `label = pdf_index`。封面 index 0 不标页码。

换书时重做 1–4。28 和 29 是这一本的常数。

## 2. 正文：按块读，一块是一段

`page.get_text("blocks")` 在这一本上，一块约等于一段或一个标题。按 `(y, x)` 排序。只留 `block_type == 0` 的文字块。

块内各行收成一段：

- 普通换行改成空格。
- 行末是 `-` 时走第 4 节的连字符规则。
- 行末是 `–` 或 `—` 时直接拼接，不加空格，避免 `1820– 1900`。

### 页眉页脚

用坐标删，不用「像标题就删」。这一本页高约 589：

- `y < 20` 的块是跑页眉（`14 Theodore M. Porter`、`viii Contents`），删。
- 整块只有页码或罗马数字，删。页脚页码多在 `y > 540`。
- 含 `Cambridge Histories Online` 的块，删。

章节标题和 Part 扉页在 `y ≈ 60` 以下，会留下来。处理前看一眼 Part 扉页的 y，确认没被页眉规则误伤。

## 3. 索引：另一套阅读顺序

索引是双栏。`get_text("blocks")` 会把左右栏按 y 交织，词条顺序就乱了。从索引第一页起改用 `get_text("dict")` 的行，并带上每行的 x。

这一本索引从 pdf index 763 开始。判断方法：目录里 Index 的印刷页，换算成 pdf index。

阅读顺序：

1. 居中的 `INDEX` 标题先写。
2. `x < 页宽/2` 的行按 y 排成左栏，然后右栏。
3. 新词条在栏的左缘（这一本左栏约 x=41，右栏约 x=203）。
4. 续行向右缩进约 8pt。`x` 比该词条首行大 4pt 以上，就接到上一条，例如 Adorno 的 `546,` 接到下一行的 `550, 604`。
5. 小写开头不一定是续行。`accounting. See management accounting` 是新词条。只用缩进判断，不用首字母大小写判断。

---

## 4. 连字符：只接软连字符

行末的 `-` 有两种。`cen-` + `tury` 应成 `century`。`eighteenth-` + `century` 应保持 `eighteenth-century`。

设 `pre` 为连字符前的字母，`suf` 为下一行开头的字母，`joined = pre + suf`。用系统词表，并承认简单屈折（`-s`、`-es`、`-ies`→`-y`、`-ed`、`-ing`）：

1. `joined` 是词，且 `pre` 和 `suf` 不都是词 → 去掉连字符。`century`、`societies`、`offense` 走这里。
2. `pre` 和 `suf` 都不是词，且两边都长于 1 → 去掉连字符。这是词表没收录的软连字符。
3. 其余保持连字符。`well-defined`、`pre-war`、`Evans-Pritchard` 走这里。

同一规则再扫一遍段落内部。PDF 有时把软连字符存成普通 `-`，不在行末，例如 `so-cieties`。

跨页只移动下一个段落的第一个词。段落以 `-` 结尾、下一页以小写开头时才接。接完后页码标记仍放在两页之间。不要把下一页整段拖上来。

## 5. 字符修复，点到为止

在拼行之前做，顺序固定：

1. 连字：`ﬁ→fi`，`ﬂ→fl`，`ﬃ→ffi`，`ﬄ→ffl`。
2. 浮空变音符号写在字母前面，字母类要包含无点 `ı`：`´e→é`，`` `e→è ``，`¨ı→ï`，`ˆı→î`，`ˇs→š`，`¯a→ā`。
3. 软音符在字母后面：`c¸→ç`。
4. 标点后缺空格，且标点前是小写：`category,and` → `category, and`；`end.The` → `end. The`。不要动 `U.S.` 这种大写缩写。
5. 全书只出现一两次、且含义明确的坏词，可以单点替换，例如 `strructures`、`Commmittee`、`engineeering`。先全库计数，确认不是正常拼写再替换。

修完后统计这些字符应接近 0：`ﬁ ﬂ ´ ¨ ˆ ˇ ¯ ` ¸`。

## 6. 写出文件

结构：

```text

出版信息

Contents
```

目录来自 PDF outline（`doc.get_toc()`），页码换算成第 1 节的同一套印刷页码。没有 outline 就从印出来的目录页解析，不要留空。

空页不写标记。文件写到 PDF 旁边，需要时再复制到桌面。

## 7. 收尾检查

全部通过再告诉用户文件可用。

1. 抽读一页章节正文，而不是只看 grep。确认是完整句子，页眉不在正文里，标题还在。
2. 抽一个用户点名的小节，标记页码和目录一致。这一本是 `[p. 14]` 下的 `THE “SCIENCES OF MAN” IN THE EARLY MODERN PERIOD`。
3. 抽一处跨页单词。这一本第 14 页末尾 `early` 接到第 15 页的 `modern writers`。
4. 索引抽两条：一条单行（`Abbott, Edith`），一条跨行（`Adorno, Theodor W.` 含 `550, 604`）。小写词条 `accounting` 不能粘在上一条后面。
5. 计数：变音符号和连字残留接近 0；`so-cieties` 这类应变成 `societies`；`nineteenth-century` 仍带连字符。
6. 页码标记数量接近总页数减去空白页。这一本 791 页，标出约 778 处。

回复用户时给：文件路径、搜索标记怎么写、已知限制。不要粘贴正文。

## 8. 扫描版：OCR

第 0 节若三页都抽不出句子，整本按扫描件处理。中文第七卷 PyMuPDF 和 pypdf 在章节开头、中部和索引上都是 0 字符。它有 282 条 outline，页码是 PDF 页，不是印刷页。

不要把英文版的连字符、变音符号和 `y < 20` 页眉规则搬过来。OCR 先出带坐标的字，再按这一本的版面写规则。

### 分辨率与引擎

先看嵌入图，不要盲目放大。这一本每页一张图，约 1000×1409、4-bit 索引色。把页面渲成和图像一样的像素：`zoom = image_width / page.rect.width`。放到 2000 像素宽不会多出笔画。

本机没有 Python 的 Vision 绑定。用 Swift 调 `VNRecognizeTextRequest`：`zh-Hans` 加 `en-US`，`recognitionLevel = .accurate`，打开语言校正。单页约 1.3 秒。4 路并发跑完 722 页约 7 分钟。一个进程吃完整目录，不要一页起一个进程。

流水线：

1. PyMuPDF 把每页渲成 PNG。40 页约 1.3 秒，722 页约 24 秒。
2. OCR 写成 JSONL。每页一行：`{"i": 39, "w": [{"x": 0.06, "y": 0.99, "t": "12"}]}`。`x`、`y` 是 Vision 的归一化坐标，原点在左下，`y` 用框的中线。越靠近页顶，`y` 越大。
3. 用 Python 做栏序、分段和页码。版面规则等抽看过章节开头、续页、索引、前辅文之后再写。

### 印刷页码

不要用 OCR 读到的页码当标记。罗马数字和毛笔体数字会认错：这一本把 `viii` 读成 `xxii`，把 `x` 读成 `xi`，把 `13` 读成 `巧`。页码以看见图为准，再拿第二个锚点核对。

这一本的常数：

- 正文从 pdf index 28 起，那一页印的是第 1 页。index 39 的页眉是 `12`，旁边是书名。所以 index ≥ 28 时，`印刷页 = index - 27`。
- 目录印着「第一部分」在第 9 页，对应 index 36，和上面的式子一致。
- 前辅文：index 15 的页眉是 `viii`，index 17 是 `x`，所以 `罗马数字 = index - 7`（结果小于 1 就不标）。这是裁切页眉图看出来的，不是 OCR 文本。
- 章节开头居中的 `2` 是章号，不是印刷页码。真正的页码在续页页眉一侧。
- `get_toc()` 给的是 1-based PDF 页。文件开头的目录要用上面同一套式子换算，不能把 outline 的页码直接写进去。

### 页眉，以及差点被删掉的部题

Vision 的 `y > 0.975` 才是跑页眉：页码、`剑桥科学史`、续页上的章节名。正文在续页上大约从 `y = 0.95` 开始。

第一次把截止线放在 `0.96`，部题扉页上的「第一部分」在 `y = 0.967`，被当成页眉删了。部题就在页眉下沿。改阈值之前先看部题扉页的 `y`。

另外删掉 `y > 0.90` 且整行只是阿拉伯数字、罗马数字或书名的行。脚注和责编注在 `y ≈ 0.05`，留下。英文版页脚可以删，这一本的页底是正文。

### 行、段、栏

同一行：`|Δy| ≤ 0.012`，再按 `x` 从左拼。汉字之间不加空格；`x` 间隔大于 0.02，或两边都是拉丁字母，才加空格。中英文人名因此能接在同一条里。

先按原始框判断双栏，再分栏，再并成行。若先并成行，左右栏同一高度的词条会被收成一行，行的 `x` 只剩左边，双栏检测就变成 0 页。这一本索引实际有 46 页双栏。

双栏条件，都在 `0.15 < y < 0.88`：

- 左侧 `x < 0.32` 至少 8 个框，右侧 `x > 0.48` 至少 8 个框。
- 右侧不能大多是短页码。短页码（整词是数字，或长度 ≤ 4）超过右侧 60%，这是目录页的右边距，不是索引。按双栏去读，标题和页码会拆到两头。
- 右侧总字数至少 40。

命中后从 `x = 0.45` 切开，左右各自从上到下读。栏内一行的 `x` 比该栏中位 `x` 大 0.02，就是缩进续行，接到上一条。这一本续行常以 `～` 开头。居中的「索引」会落在左栏，可能和分节字母 `A` 粘在一起，可以留着。

单栏分段：

- 段首缩进。续行大约 `x = 0.07`，新段大约 `x = 0.12`。`x` 比上一行大 0.03 且本身大于 0.10，就另起一段。
- 行距约 0.026，段与段之间也差不多，不能靠行距分段。
- 仍要把 `y` 间隔大于 0.05 的两行拆开。部题扉页只有两行，「第一部分」和副题间隔 0.073。若用「大于中位行距的倍数」来切，唯一的间隔就是中位数，两行会粘成「第一部分19世纪晚期的社会科学」。

### OCR 的收尾检查

1. `[p. 1]` 是导论的开头句，页眉书名不在正文里。
2. `[p. 9]` 单独有「第一部分」，没有被页眉规则吃掉。
3. 用户点名的小节在对的标记下。这一本 `[p. 12]` 有「近代早期的“人的科学”」。
4. 前辅文抽一页。这一本 `[p. x]` 是致谢。
5. `[p. 646]` 起是索引：左栏词条分开，缩进续行接在上一条，右栏不是按 y 插进左栏。目录页没有被当成双栏。
6. 双栏页数量接近索引篇幅，不是全书。这一本 46 页。
7. 页码标记接近总页数减去空白页。722 页标出 709 处。
8. 抽查时发现的错字已经改过，并且用改后的词再搜过一遍。

交付时写明：索引里的页码是原书旁码；抽查中改过哪些错字。不要把整页正文贴进对话。扫描大约 1000 像素宽，没被看到的页仍可能有错字。

### 发现的错字要改

抽查正文、标题、索引时，看出错字就改 txt，不要留到交付说明里就算完成。这一本抽查里已经能确定的例子：`传人` 应为 `传入`，`咄咄通人` 应为 `咄咄逼人`，`敏陷` 应为 `缺陷`。

改法：

1. 先改这一处。上下文不够判断时，打开该页的扫描图核对，再改。
2. 用改前的整词再搜全书。同一错法的每一处都改。`传入` 这种词可以整词搜；不要把单个字 `人` 全局换成 `入`。
3. 一个字在别处可以是正确的，就只改已经核对过的那几处。`巧` 可以是真字，只有确认本页印的是 `13` 时，才把这一处改成 `13`。
4. `[p. N]` 仍只用页眉锚点算出的印刷页码。页眉上被认错的数字用来发现错字，不拿来改标记。

### OCR 做过、不要再做

- 不要把 OCR 认出来的页码写成 `[p. N]`。罗马数字和残笔数字不可靠，标记只来自看过图的锚点。
- 不要把英文版的页眉阈值原样拿来。`y > 0.96` 在这一本删掉了部题，`0.975` 才留住它。
- 不要先合并同行再检测双栏。左右词条会并成一行，索引栏序消失。
- 不要把目录页的右侧页码当成第二栏。
- 不要放大低分辨率扫描图指望多认出字，也不要一页启动一次 OCR 进程。
- 不要用英文词表去切中文 OCR。
- 不要把单个字做全书替换。`人` 换成 `入`，或 `巧` 换成 `13`，会改掉本来正确的字。错字按上面的整词、逐处核对来改。

## 做过、不要再做

下面是英文文字版上的失败。扫描版的失败在第 8 节末。

用词典把没有空格的长串重新切词。英文版大约四分之一的页有至少一处粘连，多在脚注、斜体书名和个别紧排句子，例如 `scientistsofteninvoke...`。

按词频或按词长平方去切，会把对的句子切坏：`part of its` 变成 `parto fits`，`was in turn modulated` 变成 `wa sin turn mo du lated`。短词（`as`、`of`、`her`、`fin`）和词表里的怪词（`sare`、`aswell`）会赢过正确切分。

按大小写切开短 token 也会伤到人名：`MacIver`、`MacKenzie`。

这些粘连留在原文里，并在交付说明里写一句。主章节的句子已经是分开的，检索和阅读都够用。不要在文字版流程里全局切词。扫描版走第 8 节的 OCR，也不要接着用词典把 OCR 结果再切一遍。

## Agent 循环

每一步只在上一步的抽查通过后进入下一步。失败就改规则，不要加一层新的全局替换。第 0 节抽出句子，走文字层；三页都是空的，走 OCR。

文字层：

1. 两套提取器各抽 3 页，选定提取器。
2. 用两个锚点算出印刷页码偏移，写成这一本书的常数。
3. 正文按块重排，删页眉页脚。抽读一页章节。
4. 加上连字符和字符修复。再抽读同一页，并搜一个已知软连字符。
5. 若有双栏索引，从索引首页切换到按 x 排序的路径。抽读两条词条。
6. 写目录和 `[p. N]` 标记，跑第 7 节的计数。
7. 文件落到 PDF 旁边。回复路径、标记格式、粘连长串这一项限制。

OCR：

1. 确认三页都没有文字层，并看嵌入图的像素尺寸。按原图像素渲染，先 OCR 章节开头、续页、索引、前辅文各一页。
2. 看着页眉图定两个锚点，写出印刷页码式子。不用 OCR 文本里的页码。
3. 全本 OCR 成带 `x`、`y` 的 JSONL。先用原始框判断双栏，再并行。
4. 页眉截止线用部题扉页核对。这一本 `0.96` 会删掉「第一部分」，`0.975` 不会。
5. 按缩进分中文段落，`y` 间隔大于 0.05 的标题行拆开。
